# Streamlit interface

This folder provides the interactive web UI. Run `streamlit run app.py` from this directory after starting the FastAPI service. The UI collects questions, displays answers and source cards, and includes pages for history, documents, settings, and project information.

Set `RAG_API_URL` if the API is not running on `http://localhost:8000`.
